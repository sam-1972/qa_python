# Тестирование приложения BooksCollector

Проект содержит тесты для класса `BooksCollector`, реализованные на языке Python с использованием фреймворка `pytest`.

## Описание тестируемого функционала

Класс предназначен для управления библиотекой книг: назначения им жанров и ведения списка избранного.
Основные ограничения:
*   Название книги: от 1 до 40 символов.
*   Доступные жанры: 'Фантастика', 'Ужасы', 'Детективы', 'Мультфильмы', 'Комедии'.
*   Жанры с возрастным рейтингом (недоступны детям): 'Ужасы', 'Детективы'.

## Покрытые сценарии тестирования

Для обеспечения надежности работы приложения были реализованы следующие проверки:

1.  **Управление каталогом книг (`add_new_book`)**:
    *   Успешное добавление валидной книги.
    *   Отказ в добавлении при пустом названии или длине более 40 символов.
    *   Защита от дубликатов (одну книгу нельзя добавить дважды).
    *   Проверка начального состояния: у новой добавленной книги жанр отсутствует (пустая строка).

2.  **Назначение жанров (`set_book_genre`, `get_book_genre`)**:
    *   Успешная установка жанра для существующей книги.
    *   Корректное получение жанра по названию.
    *   Защита от установки жанра несуществующей книге или использования недопустимого названия жанра.

3.  **Поиск и фильтрация (`get_books_with_specific_genre`, `get_books_for_children`)**:
    *   Поиск всех книг заданного жанра.
    *   **Книги с возрастным рейтингом корректно исключаются из списка детских произведений.** (Например, жанр «Ужасы» не попадет в выдачу метода `get_books_for_children`).

4.  **Работа со списком «Избранное» (`add_book_in_favorites`, `delete_book_from_favorites`)**:
    *   Добавление книги в избранное возможно только если она есть в основном каталоге.
    *   Защита от повторного добавления одной и той же книги в избранное.
    *   Безопасное удаление книги из избранного (метод игнорирует запрос, если книги нет в списке).
    *   Получение актуального списка избранных книг.
